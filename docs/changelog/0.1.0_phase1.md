# Changelog - Version 0.1.0 (Phase 1 : Data Models)

**Date** : Mars 2026

## Vue d'ensemble

Phase 1 pose les fondations du package : initialisation de l'outillage, extraction complète des modèles Django en Pydantic purs, et mise en place des contrats de configuration et d'erreurs. Aucune logique métier ici — uniquement des types, des structures et des validations strictes.

---

## Ajouts ✨

### ⚙️ Infrastructure du projet

- **Initialisation du package** : structure `src/ai_engine/` avec `pyproject.toml` et gestion des dépendances via `uv`.
- **`py.typed`** : marqueur PEP 561 pour la compatibilité des type-checkers (`mypy`, `pyright`).
- **`from __future__ import annotations`** appliqué systématiquement pour les forward references.

### 🧱 Modèles de données Pydantic (`src/ai_engine/models/`)

Conversion de tous les modèles Django ORM du monolithe en `pydantic.BaseModel` purs, sans aucune dépendance à Django.

- **`LLMProviderConfig`** (`models/provider.py`) — Configuration d'un fournisseur LLM :
  - Champs : `id` (UUID auto), `name`, `provider_type`, `default_model`, `api_key` (`SecretStr`), `api_base_url`, `extra_secrets`
  - Sous-modèles associés : `ProviderCapabilities` (vision, function_calling, streaming, context_window), `PricingConfig` (tarification input/output), `ProviderSettings` (temperature, max_tokens, timeout, retries, top_p, penalties)
  - Remplacement du `JSONField` Django opaque par des champs typés explicites

- **`Agent`** + **`AgentConfig`** (`models/agent.py`) — Agent AI :
  - `Agent` : `id`, `name`, `slug`, `description`, `role` (`AgentRole`), `provider_id` (référence par ID, remplace `ForeignKey`)
  - `AgentConfig` : configuration comportementale (`max_iterations`, `max_tokens_per_run`, `temperature` override, `enable_memory`, `enable_tools`, `enable_rag`, `retry_on_failure`, `max_retries`, `extra`)

- **`ToolDefinition`** (`models/tool.py`) — Définition d'un outil de function calling :
  - Champs : `key`, `name`, `description`, `tool_type`, `parameters_schema` (JSON Schema OpenAI), `function_path`, `connector_id`, `config`, `requires_approval`, `is_dangerous`, `is_active`

- **`Skill`** + **`AgentSkillAssignment`** (`models/skill.py`) — Capacité de haut niveau :
  - `Skill` : `key`, `name`, `category` (`SkillCategory`), `system_prompt`, `required_tool_ids`, `config`, `recommended_provider_id`
  - `AgentSkillAssignment` : association agent ↔ skill avec `proficiency` (`Proficiency`), remplace le `ManyToManyField` Django

- **`Message`** (`models/message.py`) — Message de conversation :
  - Éclatement du `JSONField metadata` Django en types forts : `tool_calls: list[ToolCall]`, `tool_result: ToolResult | None`, `token_usage: TokenUsage | None`
  - Sous-modèles : `ToolCall` (compatible format OpenAI `tool_calls`), `ToolResult` (lié par `tool_call_id`), `TokenUsage` (prompt/completion/total tokens + coût estimé USD)

- **`Conversation`** (`models/conversation.py`) — Session de chat (concept nouveau, absent du Django) :
  - Découplage explicite : `Conversation` (session utilisateur) ≠ `Execution` (exécution technique)
  - Champs : `title`, `agent_id`, `owner_id`, `status` (`ConversationStatus`), `summary`, `message_count`, `total_tokens`

- **`Execution`** + **`ExecutionStep`** (`models/execution.py`) — Traçage d'exécution :
  - `Execution` : session complète (`agent_id`, `conversation_id`, `status`, `token_usage`, `duration_ms`, `error`)
  - `ExecutionStep` : chaque étape atomique (`step_type` (`StepType`), `order`, `input_data`, `output_data`, `tool_id`, `duration_ms`)

- **`Graph`** + **`GraphNode`** + **`GraphEdge`** (`models/graph.py`) — Workflows multi-agents :
  - Éclatement du `JSONField definition` Django en types forts
  - `GraphNode` : `node_id`, `node_type` (`NodeType` : AGENT, CONDITION, TOOL, PARALLEL, LOOP, INPUT, OUTPUT), `config`, `position_x/y`
  - `GraphEdge` : `source_node_id`, `target_node_id`, `condition` (expression Python évaluable), `label`
  - `Graph` : `nodes: list[GraphNode]`, `edges: list[GraphEdge]`, `entry_node_id`, `state_schema`, `status` (`GraphStatus`)

- **`AgentMemory`** (`models/memory.py`) — Mémoire persistante d'un agent :
  - Types : `SHORT_TERM`, `LONG_TERM`, `EPISODIC` (`MemoryType`)
  - Champs : `agent_id`, `key`, `content`, `importance_score`, `access_count`, `last_accessed_at`

- **`KnowledgeSource`** + **`Document`** + **`Chunk`** (`models/knowledge.py`) — RAG (Retrieval-Augmented Generation) :
  - `KnowledgeSource` : remplacement du `FileField` Django par `file_path: str | None`, `agent_ids: list[str]` (remplace `ManyToManyField`)
  - `Document` : `source_id`, `title`, `content`, `source_type` (`SourceType`), `index_status` (`IndexStatus`)
  - `Chunk` : fragment de document avec `embedding: list[float] | None` pour la recherche sémantique

### 🔴 Hiérarchie d'exceptions (`src/ai_engine/exceptions.py`)

Toutes les exceptions héritent de `AIEngineError` (base commune). Jamais de `raise Exception(...)` nu dans le code.

| Classe | Héritage | Message auto |
|---|---|---|
| `ProviderNotFoundError` | `ProviderError` | `"Provider '{id}' not found."` |
| `UnsupportedProviderError` | `ProviderError` | avec liste des types disponibles |
| `APIKeyMissingError` | `ProviderError` | avec hint variable d'environnement |
| `AgentNotFoundError` | `AgentError` | `"Agent '{id}' not found."` |
| `AgentDisabledError` | `AgentError` | |
| `ConversationNotFoundError` | `ConversationError` | |
| `GraphNotFoundError` | `GraphError` | |
| `ExecutionNotFoundError` | `ExecutionError` | |
| `ToolNotFoundError` | `ToolError` | |
| `ToolExecutionError` | `ToolError` | avec `tool_name` + `detail` |
| `StorageError` | `AIEngineError` | |
| `StorageConnectionError` | `StorageError` | |
| `MissingDependencyError` | `AIEngineError` | avec hint `pip install ai-engine[extra]` |

### ⚙️ Configuration (`src/ai_engine/config.py`)

- **`Settings`** (Pydantic Settings) : variables d'environnement préfixées `AI_ENGINE_`, chargement depuis `.env`
  - `debug`, `log_level`, `default_provider_type`, `default_model`
  - `openai_api_key`, `anthropic_api_key` (clés de commodité)
  - `default_storage`, `sqlite_db_path`, `json_storage_path`
  - `max_tool_iterations`, `default_temperature`
- **`get_settings()`** : factory avec cache `@lru_cache` pour un singleton partagé
