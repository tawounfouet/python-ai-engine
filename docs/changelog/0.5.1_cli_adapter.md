# Changelog — Version 0.5.1 (CLI Adapter)

**Date** : Avril 2026  
**Branche** : `phase5/cli-adapter`

---

## Vue d'ensemble

`0.5.1` livre le **premier adaptateur concret de Phase 5** : une CLI complète
construite sur [Typer](https://typer.tiangolo.com/) + [Rich](https://rich.readthedocs.io/),
qui expose l'intégralité des fonctionnalités de `ai_engine` en ligne de commande.

La CLI est installée comme extra optionnel (`pip install ai-engine[cli]`) et
enregistrée comme point d'entrée système (`ai-engine`).

Prochaines étapes de la série 0.5.x :
- `0.5.2` → FastAPI adapter (`src/ai_engine/adapters/fastapi/`)
- `0.5.3` → Django adapter (`src/ai_engine/adapters/django/`)

## Fonctionnalités CLI

### Installation

```bash
pip install ai-engine[cli]
# ou
uv add ai-engine[cli]
```

### Commandes disponibles

```
ai-engine --help
ai-engine --version

# Providers
ai-engine provider list [--active]
ai-engine provider add  --name "OpenAI" --type openai --model gpt-4o --key sk-…
ai-engine provider show <id|name|prefix>
ai-engine provider delete <id|name|prefix> [--yes]

# Agents
ai-engine agent list [--active]
ai-engine agent create --name "Bot" --provider <id> --prompt "Tu es…" [--role assistant]
ai-engine agent show <id|slug|prefix>
ai-engine agent delete <id|slug|prefix> [--yes]

# Conversations
ai-engine conversation list [--agent <id|slug>]
ai-engine conversation show <id|prefix>
ai-engine conversation history <id|prefix> [--limit N]
ai-engine conversation delete <id|prefix> [--yes]

# Chat
ai-engine chat --agent <id|slug>                          # REPL interactif
ai-engine chat --agent <id|slug> --once "Bonjour !"       # single-shot
echo "Explique async/await" | ai-engine chat --agent bot --once  # pipe stdin
ai-engine chat --agent <id|slug> --conversation <id>      # reprendre une conv

# Config
ai-engine config show
ai-engine config set AI_ENGINE_AGENT mon-agent
```

### Variables d'environnement

| Variable | Défaut | Description |
|----------|--------|-------------|
| `AI_ENGINE_DB` | `ai_engine.db` | Fichier SQLite utilisé par toutes les commandes |
| `AI_ENGINE_AGENT` | — | Agent par défaut pour `chat` |
| `AI_ENGINE_LOG_LEVEL` | — | Niveau de log |

### Résolution d'identifiants

Toutes les commandes acceptent :
- **ID complet** (UUID) : `3fa85f64-5717-4562-b3fc-2c963f66afa6`
- **Slug** (agents) ou **nom** (providers) : `my-assistant`, `OpenAI`
- **Préfixe d'ID** (≥ 4 chars) : `3fa85f64`

## Architecture de la couche CLI

```
app.py  (root Typer app)
├── commands/provider.py   → sub-app "provider"
├── commands/agent.py      → sub-app "agent"
├── commands/conversation.py → sub-app "conversation"
├── commands/chat.py       → sub-app "chat"  (callback = commande principale)
└── commands/config.py     → sub-app "config"

console.py   ← affichage Rich (importé par les commandes, jamais de typer ici)
utils.py     ← get_storage / resolve_* / abort (importé par les commandes)
```

**Principes de conception :**
- Imports `ai_engine` **lazily** (à l'intérieur des fonctions) → pas de coût au chargement
- `err_console = Console(stderr=True)` → stdout propre pour le piping
- `InMemoryStorage` patchable via monkeypatch → tests isolés, sans I/O disque
